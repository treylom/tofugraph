# /tofugraph:links — 창고 링크 건강검진

노트끼리 잘 연결됐는지 검사합니다. **서버·설치·인터넷이 전혀 필요 없습니다** — 검색 엔진이 꺼져 있어도, 인덱스를 아직 안 만들었어도 돕니다. 몇 초면 끝납니다.

> ⚠️ 검색 엔진이 살아있는지 점검하는 것은 `/tofugraph:doctor` 입니다 — 이 명령은 검색 서버 상태와 **무관**하며, 결과가 나빠도 서버 수리(`/tofugraph:heal`) 대상이 아닙니다(고칠 것은 노트의 링크입니다).

## 사용

```
/tofugraph:links          → 현재 폴더를 창고로 보고 검사
/tofugraph:links <경로>    → 다른 창고를 검사할 때 경로 지정
```

## 실행 절차 (에이전트용)

1. `python3 "${CLAUDE_PLUGIN_ROOT}/scripts/graph_scan.py" doctor <창고 경로>` 를 실행한다. 경로 인자가 없으면 **현재 폴더**를 쓰되, 그 폴더가 창고(md 노트 폴더)가 맞는지 한 줄로 확인하고 진행한다.
2. 출력은 진단 6종(D1 깨진 링크 / D2 외톨이 노트 / D3 막다른 노트 / D4 허브 쏠림 / D5 표지정보 위생 / D6 표기 흔들림)이며 각 항목에 처방(`> 처방:` 줄)이 붙는다. 전체 목록이 필요하면 `--json` 을 덧붙인다.
3. 출력을 **사용자 눈높이로 요약**한다 — **건수가 많은 진단부터 2~3종만** 골라 "무엇이 몇 건, 그래서 무엇을 하면 되는지"로 옮기고, 노트 경로 나열은 상위 몇 개까지만. 외톨이 노트가 수백 건이어도 전부 읽어주지 않는다.
