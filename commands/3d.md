# /tofugraph:3d — 3D 그래프 뷰어

내 창고의 노트 연결망을 3D 로 볼 수 있는 **단일 HTML 파일**을 만듭니다. 라이브러리·데이터가 전부 파일 안에 들어 있어 서버·네트워크 없이 브라우저로 바로 열립니다.

## 실행 절차 (에이전트용)

1. `python3 "${CLAUDE_PLUGIN_ROOT}/scripts/graph3d/export_data.py"` 로 데이터를 추출하고 → `python3 "${CLAUDE_PLUGIN_ROOT}/scripts/graph3d/build_viewer.py"` 로 단일 HTML(라이브러리·데이터 전부 내장 — 서버·네트워크 불필요)로 조립한다.
2. **만들고 끝내지 않는다 — 생성 직후 바로 브라우저에 띄운다**: macOS `open <생성된.html>` / Windows `start "" <생성된.html>` / **WSL**(`/proc/version` 에 microsoft 가 보이거나 `$WSL_DISTRO_NAME` 이 있으면) `explorer.exe "$(wslpath -w <생성된.html>)"` — WSL 에서 `xdg-open` 은 브라우저가 안 뜨고 매달리므로 쓰지 않는다 / 그 외 Linux `xdg-open <생성된.html>`. 사용자가 명령 하나로 "내 창고 그래프가 화면에 떠 있는 상태"까지 도달해야 한다. 띄운 뒤 파일 경로도 한 줄 알려준다(다음에 또 열 수 있게).
3. 자동 열기가 실패한 환경에서만 "이 파일을 더블클릭하세요" 안내로 대체한다. 단 WSL 의 `explorer.exe` 는 창이 정상으로 떠도 종료코드 1 을 돌려줄 때가 있으므로 **종료코드로 실패를 판정하지 말 것** — 에러 출력이 있거나 사용자가 안 떴다고 할 때만 안내로 대체한다.
