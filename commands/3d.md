# /tofugraph:3d — 3D 그래프 뷰어

내 창고의 노트 연결망을 3D 로 볼 수 있는 **단일 HTML 파일**을 만듭니다. 라이브러리·데이터가 전부 파일 안에 들어 있어 서버·네트워크 없이 브라우저로 바로 열립니다.

## 실행 절차 (에이전트용)

1. `python3 scripts/graph3d/export_data.py` 로 데이터를 추출하고 → `python3 scripts/graph3d/build_viewer.py` 로 단일 HTML(라이브러리·데이터 전부 내장 — 서버·네트워크 불필요)로 조립한다.
2. 생성된 파일 경로를 알려주고 더블클릭하거나 브라우저로 열도록 안내한다 — 경로 + 여는 법 한 줄이면 충분.
